    Como usar

    Escolha o tipo de equação e digite os coeficientes. O resultado aparece enquanto você digita, junto com o gráfico e o passo a passo. Campos vazios valem zero, então para resolver x² − 9 = 0 basta preencher a = 1 e c = −9. Os números aceitam vírgula ou ponto decimal e notação científica, como 1,5e3 para 1500.

    No celular, alguns teclados numéricos não têm o sinal de menos. Nesse caso, digite o número e toque em ± Trocar sinal: o último campo editado troca de sinal.

    Equação do 1º grau

    Uma equação do tipo ax + b = 0 tem uma única raiz quando a é diferente de zero. Basta isolar o termo com x e dividir pelo coeficiente:

    ax + b = 0 → x = −b / a

    Exemplo: em 2x − 8 = 0, o termo isolado fica 2x = 8 e, dividindo por 2, x = 4. Se a for zero, não existe x: com b ≠ 0 a equação é impossível, e com b = 0 ela vira a identidade 0 = 0, verdadeira para qualquer valor. O gráfico mostra a reta y = ax + b; a raiz é o ponto onde ela cruza o eixo x.

    Equação do 2º grau e a fórmula de Bhaskara

    Para ax² + bx + c = 0, o discriminante Δ decide quantas raízes reais existem: duas quando Δ é positivo, uma raiz dupla quando Δ é zero, e nenhuma real (duas complexas conjugadas) quando Δ é negativo.

    Δ = b² − 4ac x = (−b ± √Δ) / 2a

    Exemplo: em x² − 5x + 6 = 0, Δ = (−5)² − 4 · 1 · 6 = 1 e x = (5 ± 1) / 2, ou seja, 2 e 3. O vértice da parábola fica em (2,5; −0,25), a forma fatorada é (x − 2)(x − 3) e a forma canônica é (x − 2,5)² − 0,25. Além das raízes, a ferramenta mostra soma e produto (−b/a e c/a), concavidade, eixo de simetria e o valor mínimo ou máximo.

    Com Δ negativo, como em x² + 2x + 5 = 0 (Δ = −16), as raízes são −1 + 2i e −1 − 2i, em que i é a unidade imaginária (i² = −1). A parábola, nesse caso, não toca o eixo x.

    Equação do 3º grau

    Toda equação ax³ + bx² + cx + d = 0 tem pelo menos uma raiz real. A conta segue o caminho clássico: divide tudo por a, troca x por t − b/(3a) para chegar à forma reduzida t³ + pt + q = 0 e calcula o discriminante dessa forma.

    Δ = (q/2)² + (p/3)³

    Quando Δ ≥ 0, a fórmula de Cardano dá uma raiz real; quando Δ < 0, usa-se o método trigonométrico, que evita raízes de números negativos. Essa raiz é refinada pelo método de Newton, e o polinômio é dividido por (x − r), sobrando uma equação do 2º grau para as outras duas raízes. Atenção ao sinal: aqui Δ < 0 indica três raízes reais distintas, o contrário do que acontece no 2º grau.

    Exemplo: x³ − 6x² + 11x − 6 = 0 tem as raízes 1, 2 e 3. Já x³ − 1 = 0 tem uma raiz real (1) e duas complexas, −0,5 ± 0,866i.

    Sistemas lineares 2×2 e 3×3

    Na aba Sistemas, cada linha é uma equação: os coeficientes de x, y e z e, depois do sinal de igual, o termo independente. A solução sai pela regra de Cramer, quando o determinante principal D é diferente de zero, e é confirmada pelo escalonamento de Gauss-Jordan.

    x = Dx / D y = Dy / D z = Dz / D

    Exemplo: para 2x + y = 5 e x − y = 1, D = 2 · (−1) − 1 · 1 = −3, Dx = −6 e Dy = −3, então x = 2 e y = 1. No caso 2×2, o gráfico mostra as duas retas e o ponto onde se cruzam.

    Se D = 0, a regra de Cramer não se aplica e a classificação vem do posto das matrizes: quando o posto da matriz dos coeficientes é igual ao da matriz aumentada, mas menor que o número de incógnitas, o sistema tem infinitas soluções; quando os postos são diferentes, não há solução.

    Precisão e limitações

    • As contas usam números de ponto flutuante com cerca de 15 algarismos; o resultado é exibido com até 10 algarismos significativos.
    • Valores menores que 10⁻¹² em módulo são mostrados como 0, para não aparecer resíduo de arredondamento como 0,0000000000001.
    • Raízes múltiplas do 3º grau são mais sensíveis: podem sair com erro na sexta casa decimal, e raízes que diferem menos de 10⁻⁷ são tratadas como iguais.
    • O gráfico escolhe sozinho um intervalo que mostra todas as raízes e o vértice ou os pontos críticos.

    Perguntas frequentes

    O que significa o i nas raízes?

    É a unidade imaginária, definida por i² = −1. Raízes como −1 + 2i aparecem quando a equação não tem solução no conjunto dos números reais; elas sempre vêm em pares conjugados quando os coeficientes são reais.

    E se o coeficiente a for zero?

    A equação perde o grau mais alto e é resolvida com o grau imediatamente menor. Por exemplo, na aba de 2º grau, 0x² + 2x − 8 = 0 é resolvida como 2x − 8 = 0, com um aviso no resultado.

    Por que algumas raízes aparecem como 0,3333333333?

    Porque o resultado tem até 10 algarismos significativos. Raízes irracionais ou dízimas, como 1/3 ou √2, não têm representação decimal finita, então são mostradas arredondadas.

    Dá para resolver sistemas com mais de três incógnitas?

    Aqui não. Para sistemas maiores, monte a matriz dos coeficientes na ferramenta de matrizes, que trabalha com até 6 × 6 e calcula determinante e inversa.

    Os números que digito são enviados para algum lugar?

    Não. Tudo é calculado no seu navegador. Os últimos coeficientes ficam guardados apenas neste aparelho, para você continuar de onde parou.
