Conversor de arquivos

Arraste os arquivos, escolha o formato e baixe o resultado. Tudo acontece no seu navegador: nenhum arquivo é enviado para servidor nenhum.

Arraste os arquivos aqui ou

Aceita JSON, CSV, Markdown, texto, PDF, DOCX, PNG, JPG, WebP, BMP e ZIP. Vários arquivos de uma vez.

Arquivos

    O que já converte

    • JSON → CSV: pega uma lista de objetos e monta a planilha com todas as colunas; valores com vírgula ou aspas vão entre aspas, e o arquivo sai com BOM para o Excel abrir os acentos certo.
    • CSV → JSON: lê a primeira linha como cabeçalho, transforma cada linha em um objeto e converte número em número de verdade.
    • Markdown → HTML: títulos, listas, negrito, itálico, código e links, com o HTML escapado (nada de script entrar por acidente).
    • Imagens: PNG ⇄ JPG ⇄ WebP ⇄ BMP. A conversão usa o próprio navegador (canvas) e, no BMP, um codificador escrito aqui, sem biblioteca. Imagem com transparência vai para JPG ou BMP com fundo branco, porque esses formatos não guardam transparência.
    • PDF → DOCX (visual): gera um .docx com cada página como imagem, em A4 com margem de 1 cm. Abre no Word igual ao PDF — imagens, colunas, tabelas e posições — e é a opção mais parecida com "converter PDF em Word" que dá para fazer sem serviço externo. O texto fica dentro da imagem, então não é editável.
    • PDF → HTML visual: cada página é renderizada e entra no HTML como imagem, então o resultado fica igual ao original. É a opção certa quando você quer "ver igual" no navegador.
    • PDF → TXT: extrai o texto preservando o layout — a posição de cada trecho vira coluna de texto, então a indentação, as colunas (CPF / RG, Cargo / Matrícula) e as linhas em branco ficam parecidas com o PDF, e cada página termina em quebra de página. É o mesmo critério dos conversores "layout" de linha de comando. O que nenhum extrator resolve: palavra que o PDF desenhou como bloco único, sem o caractere de espaço, sai junta — e imagem não existe em TXT.
    • Word (DOCX) → HTML ou texto: o .docx é lido direto (é um ZIP com word/document.xml), parágrafo por parágrafo, então não depende de biblioteca externa. É só ida: o navegador não escreve .docx fiel, e é por isso que PDF ⇄ DOCX não aparece nesta ferramenta.
    • ZIP: solte um .zip para o conteúdo entrar na fila e ser convertido, e use Baixar em .zip para levar todos os resultados num pacote só. Nomes repetidos viram "arquivo (2)" dentro do pacote, em vez de um sobrescrever o outro.
    • Word (DOCX) → HTML ou texto: lê o .docx com o mammoth e devolve a página HTML (títulos, listas, negrito, tabelas simples) ou o texto puro. É só ida: o navegador não escreve .docx fiel, e é por isso que PDF ⇄ DOCX não aparece nesta ferramenta.

    Resumo do que já vai e volta: texto (JSON, CSV, Markdown, TXT e PDF), imagens (PNG, JPG, WebP e BMP), DOCX só como origem e ZIP para agrupar. Nada de servidor: tudo roda no seu navegador, e as bibliotecas de PDF, DOCX e ZIP só são baixadas quando você usa aquele formato.

    Imagens (PNG, JPG, WebP e BMP) e arquivos de texto já vão e voltam. ZIP, PDF e DOCX entram nas próximas etapas — a matriz da ferramenta só mostra o que já funciona, para você nunca ver uma conversão que promete e não entrega.

    Por que tudo fica no navegador

    arquivo → leitura local → conversão em JavaScript → link de download

    Como o processamento é local, o arquivo não sai do seu computador, não há limite de tamanho imposto por servidor e a ferramenta funciona mesmo sem conexão depois de carregada. O preço é que formatos muito complexos (como PDF ⇄ DOCX) exigem bibliotecas grandes ou serviço especializado.

    Perguntas frequentes

    Meus arquivos são enviados para algum lugar?

    Não. A conversão roda em JavaScript na sua máquina, com a API de arquivos do navegador. Fechar a aba descarta tudo.

    Dá para converter vários arquivos de uma vez?

    Sim: arraste quantos quiser, escolha o formato de cada um e use Converter. A barra mostra o progresso do arquivo e o total, e um arquivo com erro não trava os outros.

    O CSV abre no Excel com acento errado?

    Não: o arquivo sai com BOM (UTF-8 com marca), que é o que o Excel precisa para reconhecer os acentos. Se o seu programa reclamar, importe como UTF-8.
